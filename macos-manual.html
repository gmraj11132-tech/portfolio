macOS Web OS (Apple Sequoia Edition)

A full-fidelity, browser-based recreation of macOS Sequoia built with modern web technologies. Engineered with a realistic boot sequence, login/lock screen, Siri assistant with audio synthesis, Finder virtual filesystem, native GitHub & LinkedIn apps, auto full-screen, and mobile landscape auto-orientation.

 Core OS Engines

  • ✓ WindowManager: Multi-window management with z-index stacking, focus control, minimization, maximize-to-viewport, and smooth mouse/touch dragging.
  • ✓ Virtual FileSystem: Hierarchical UNIX virtual filesystem mounted at /Users/admin/ with LocalStorage persistence.
  • ✓ Boot & Auth Sequence: Realistic Apple startup progress loader, followed by user avatar login with credential authentication and sleep/restart controls.
  • ✓ Task Manager (Force Quit): Interactive ⌥⌘⎋ modal to inspect running processes and terminate windows on demand.

📱 Mobile & Fullscreen Experience

  • ✓ Automatic Full Screen: On the very first user interaction (click/touch), triggers native full screen without friction.
  • ✓ Orientation Lock API: Automatically requests landscape lock on supported mobile devices to guarantee desktop fidelity.
  • ✓ Rotate Device Guidance: Displays a 3D animated rotation card when viewed in portrait on handheld devices.
  • ✓ Responsive Dock Scaling: Scales down to 30px compact icons in mobile landscape mode so all 18+ apps fit comfortably.

🎙️ Siri AI & Web Audio API

  • ✓ Interactive Siri Assistant: Glowing multi-color conic sound orb with dialogue history and smart responses.
  • ✓ Audio Synthesizer: Zero external audio files required — Web Audio API generates authentic click and chime frequencies in real-time.
  • ✓ Contextual Query Answering: Instant answers for Aryan's biography, portfolio projects, weather, tech jokes, and app launching.
  • ✓ Prompt Chips: One-tap suggestion chips for rapid user engagement.

🗂️ 18+ Built-in Applications

  • ✓ About This Mac (Aryan Raj Edition): 5-tab personal biography, projects showcase, 12 credentials, and resume viewer.
  • ✓ Native GitHub & LinkedIn Apps: Live profile viewers synced with @gmraj11132-tech and Aryan's LinkedIn.
  • ✓ Terminal: Functional shell with custom commands (whoami, neofetch, projects, bio, clear).
  • ✓ Productivity Suite: Safari, Notes, TextEdit, Calculator, Weather, Music, Maps, and App Store.

⚡ Technology Stack & Deployment

Engineered without heavy frameworks for raw performance, 60fps animations, and instantaneous load times:

Language: Vanilla JavaScript (ES6+), HTML5, CSS3 Glassmorphism Web APIs: Fullscreen API, Screen Orientation Lock API, Web Audio API, Web Battery API Styling: CSS Backdrop-Filter, Conic Gradients, Flexbox/Grid Architecture, CSS Keyframes Server & Host: Node.js / Express Backend, Deployed Globally on Vercel Production Repository: https://github.com/gmraj11132-tech/macos-web-os Live Production: https://macos-web-os-ashy.vercel.app
